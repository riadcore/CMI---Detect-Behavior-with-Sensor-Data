# CMI---Detect-Behavior-with-Sensor-Data
BFRBs like hair pulling and skin picking pose physical and social risks. Using Helios wristbands with IMU, thermopile, and ToF sensors, we built a model for detection. It achieved binary classification (F1=1.0), MacroF1 = 0.57 for fine-grained gestures, and an official score of 0.7841. Strong binary detection yet harder gesture-level separation.
